# Machine-learning-applied-to-KEGG-metabolic-pathway-databases-for-personalized-nutrition
Every individual is different, and our bodies can respond differently to the same nutrients and diets. **Personalized nutrition** aims to account for these differences by tailoring dietary recommendations to individual characteristics. This project explores how machine learning and KEGG metabolic pathway data can support this approach.
## Project Objective

The objective of this project was to explore the application of **machine learning to KEGG metabolic pathway data** related to nutrition, and to identify relationships between metabolic information and nutritional characteristics.

## Dataset

The dataset was extracted from the **KEGG metabolic pathway database** and focused on metabolism related to nutrition. It contained information about:

- Metabolic pathways
- Enzymes
- Substrates
- Products
- Nutritional characteristics

## Methodology

The project was implemented using **Python** and **Google Colab**.

The workflow included:

1. Data loading and preprocessing
2. Encoding categorical variables
3. Splitting the dataset into training and testing sets
4. Training a **Decision Tree Classifier**
5. Evaluating the model using classification accuracy

## Results

The Decision Tree model achieved an accuracy of approximately **72.34%** on the test set.

This result demonstrates the potential of machine learning for extracting patterns from metabolic pathway data, while also highlighting the importance of data quality and further model improvement.
